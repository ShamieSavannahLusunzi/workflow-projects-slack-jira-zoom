# Workflow Projects - Slack, Jira, Zoom

This repository contains academic case studies focused on Agile process improvement, team communication, and removing impediments.

**Projects Included:**

- Slack: Improving team communication with structured tags and escalation routes.
- Jira: Automating blocker identification and reducing administrative waste.
- Zoom: Building psychological safety in meetings with anonymous feedback.

**What's included:**
- Individual PDFs for each case study
- Combined case study document: `Agile_Process_Improvement_Case_Studies.pdf`
